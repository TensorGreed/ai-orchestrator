Signed triggers

Inbound webhooks are checked before the workflow runs.

App triggers verify the sender's signature scheme; the generic webhook supports bearer tokens and HMAC-SHA256 with a replay window.

Stripe

Verifies the Stripe-Signature header (HMAC-SHA256 over the timestamp and body) within a replay window.

GitHub

HMAC-SHA256 over the raw body, checked against X-Hub-Signature-256.

Slack

Signing-secret verification of X-Slack-Signature with a timestamp check.

Discord

Ed25519 signature verification with the application's public key.

Telegram

Matches X-Telegram-Bot-Api-Secret-Token against the configured secret.

Generic webhook

none, bearer_token or hmac_sha256 on any webhook_input, with optional idempotency keys.
